# Design：测试 UI 与未来控制面板

当前没有产品设计系统或已批准的品牌规范。现有 UI 仅自有原生测试窗口，刻意保持简单。

## 已实现的 fixture 布局

- 520×440 初始窗口；原生可调整大小。
- 垂直 stack，20 点外边距，12 点间距。
- 460 点公开文本字段与模拟 secure 字段。
- 明确标签的 submit、replace、reorder、delayed、save、reset 按钮。
- 顶部测试数据警告，底部状态标签。

这里只验证控件/状态行为，没有运行可见 UI 视觉验收。不声称小窗口、缩放或所有辅助功能布局已经通过。

## 未来产品面板

CU-016 的优先级：准确目标、mode、控制期限、审批来源、执行阶段、停止入口与能力限制。后台失败必须显示 unavailable，不用动画掩盖。

暂不做光标动画、直播、复杂 dashboard。颜色不能成为唯一状态提示。正式视觉规范随真实宿主 UI 设计落地，不从测试 app 的按钮排列推导。
